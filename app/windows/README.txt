ريبو — التربية الفنية للمرحلة المتوسطة  ·  Windows edition 1.0.0
===============================================================

التشغيل:
  انقر نقرة مزدوجة على Rebo.exe. لا يحتاج تثبيت، ويعمل دون إنترنت.

المتطلبات:
  • Windows 10 (64-bit) أو أحدث، أو Windows 11.
  • مكوّن Microsoft Edge WebView2 Runtime (مثبّت افتراضيًا في Windows 11
    ويأتي مع متصفح Edge في Windows 10). إذا ظهرت رسالة تفيد بغيابه فثبّته من
    المصدر الرسمي لشركة Microsoft:
        https://developer.microsoft.com/microsoft-edge/webview2/

محتوى المجلد:
  Rebo.exe              التطبيق
  www\                  محتوى التطبيق (لا تحذفه)
  WebView2Loader.dll    محمّل صغير مبني من المصدر للاتصال بمكوّن WebView2

الملفات المحفوظة:
  يحفظ التطبيق تقدّم القراءة والتفضيلات داخل ملف التعريف الخاص بـ WebView2
  في:  %APPDATA%\Rebo.exe\
  ويمكن حذف هذا المجلد لإعادة التطبيق إلى حالته الأصلية.

المصدر العلمي للمحتوى:
  دليل معلم التربية الفنية للمرحلة المتوسطة — وزارة التربية، جمهورية العراق.
