# مِرسم — التربية الفنية للمرحلة المتوسطة

تطبيق تعليمي عربي (RTL) يعمل **دون اتصال بالإنترنت** على **أندرويد (APK)** و**ويندوز 10/11 (EXE)**،
يحوّل محتوى مادة التربية الفنية للمرحلة المتوسطة إلى تجربة قراءة وتصفّح تفاعلية:
فهرس كامل، وعارض وحدات، وخطة درس لكل موضوع تطبيقي، واختبارات ذاتية، ولوحات مصوّرة من دليل المعلم.

## ما داخل التطبيق

| العنصر | العدد | المصدر |
| --- | --- | --- |
| الوحدات | 13 (مدخل + 12 وحدة) | `ملخص_التربية_الفنية.docx` |
| الموضوعات | 70 | الوحدات نفسها، دون اختصار أو حذف |
| أسئلة الوحدات | 66 | «أسئلة الوحدة» في الملخص |
| خطط الدروس | 4 دروس × حصتان (نظري/عملي) | `الظل والضوء`, `المنظور`, `تصميم غلاف كتاب`, `الزخرفة` |
| اللوحات المصوّرة | 13 | صفحات من دليل معلم التربية الفنية |
| المصطلحات | 21 | تعريفات حرفية من نص الوحدات |
| الرسوم المتجهة | 20 | رسوم أصلية (SVG) مرتبطة بموضوع كل وحدة |

الهدف العام للمادة (11 هدفاً) وطرائق التدريس (9 طرائق) داخل «المدخل إلى التربية الفنية».

## المزايا

- **اختيار الصف أولاً**: عند أول تشغيل يختار المتعلّم «الصف الأول/الثاني/الثالث المتوسط»، ولا يظهر بعد ذلك
  إلا محتوى ذلك الصف (الوحدات، الموضوعات، الأسئلة، اللوحات، المصطلحات، ونتائج البحث) مع المدخل العام
  والدروس التطبيقية واللوحات المشتركة. التغيير متاح في أي وقت من «الإعدادات ← الصف الدراسي».
- **فهرس تفاعلي**: تصفية بـ (الكل / غير مقروء / المفضلة)، وبطاقات لكل وحدة بقالبها وعدد موضوعاتها وأسئلتها وحالة قراءتها.
- **عرض متنوّع لكل وحدة** — خمسة قوالب تصميم مختلفة بدل تكرار بطاقة واحدة:
  `مفهومي` (لوحة تعريف + بطاقات)، `مقارن` (جدول طرفين)، `خامات` (شبكة بلاطات)،
  `خطوات` (خط زمني مرقّم)، `زمني` (شريط سنوات 1800–2100).
- **قارئ وحدة كامل**: رسوم توضيحية قابلة للتكبير، الموضوعات، مصطلحات الوحدة، لوحة الدليل، والتنقّل بين الوحدات.
- **اختبارات ذاتية**: تصحيح تلقائي للأسئلة الموضوعية، وكشف إجابة أسئلة التعداد؛ تُحفظ أفضل نتيجة لكل وحدة.
- **بحث فوري** يعمل دون شبكة، مع تطبيع للنص العربي (الهمزات، التشكيل، التطويل).
- **مفضلة وسجل قراءة**: يُستأنف موضع التمرير في كل وحدة بعد إعادة التشغيل.
- **تخصيص**: الوضع الليلي/النهاري، وأزرار **تكبير/تصغير الخط في ترويسة كل شاشة** (وشريط تمرير في الإعدادات)
  بين 90٪ و150٪، وتنسيق تلقائي للهاتف واللوح وسطح المكتب.
- **تخطيط محكم على الهاتف**: ترويسة الصفحة الرئيسية تفصل الشعار والعنوان والأدوات في مساحات مستقلة،
  وعناصر السطر الواحد (شرح الرسم وزر التكبير، ومفتاح الألوان) تبقى في سطر واحد بدل تمديدها على عدّة أسطر.
- **مشاركة**: نسخ نص الوحدة كاملاً مع الإسناد إلى المصدر.

## التشغيل والبناء

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release        # أندرويد
flutter build windows --release    # ويندوز (يتطلب Visual Studio 2022 + Desktop C++)
```

تفاصيل التوقيع والتوزيع في [`docs/BUILD.md`](docs/BUILD.md)، وبنية الكود في
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)، وخريطة المحتوى في [`docs/CONTENT.md`](docs/CONTENT.md).

## الأدوات

```bash
python3 tools/build_content.py     # يعيد توليد JSON المحتوى من ملفات المصدر

python3 tools/preview_svg.py /tmp/preview   # معاينة الرسوم كصور PNG
```
