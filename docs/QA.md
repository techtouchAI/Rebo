# خطة الفحص والجودة

## 1. المحتوى (قابل للتنفيذ محلياً، نُفِّذ)

```bash
python3 tools/build_content.py
python3 tools/verify_content.py
```

- الطبعات: `units: 13 | topics: 70 | questions: 66 | lessons: 4 | plates: 13`.
- المتحقّق: **986 فحصاً** — وجود كل جملة مصدرية، اكتمال الموضوعات، تطابق الإجابات مع الشواهد،
  اكتمال الأهداف (11) والطرائق (9)، تطابق اللوحات مع صفحاتها، غياب الاقتطاع «…».
- فحص إضافي: كل مسار أصل مذكور في JSON موجود على القرص (يُعاد أيضاً في `test/content_test.dart`).

## 3. فحص الواجهة اليدوي

| الحالة | المتوقع |
| --- | --- |
| هاتف 360×640 | `NavigationBar` سفلي، لا تجاوز أفقي، النص العربي من اليمين |
| جهاز لوحي 800×1280 | تخطيط عمود واحد، بطاقات بعرض كامل |
| نافذة ويندوز 1280×720 | `NavigationRail`، صفحة بعرض أقصى 1240 |

## 4. ما لم يُنفَّذ في هذه البيئة

لا يوجد Flutter SDK في بيئة العمل (تعذّر الوصول إلى مستودع تنزيل SDK)، لذلك:

- لم يُشغَّل `flutter analyze` ولا `flutter test` ولا أي بناء APK/EXE محلياً.
- الترجمة والتحليل والاختبارات والبناء تُنفَّذ في `.github/workflows/ci.yml` على GitHub Actions
  بمخزن Flutter الرسمي 3.35.0.

هذا مذكور صراحةً في التقرير النهائي: لا يُدّعى نجاح بناء أو اختبار قبل تنفيذه فعلياً.
